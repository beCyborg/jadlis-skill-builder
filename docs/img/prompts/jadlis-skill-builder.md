# jadlis-skill-builder

Мысль: повторяющаяся процедура один раз ложится папкой со скиллом — шаги, справочники, скрипт, — а прогон по тест-промптам возвращает правки обратно в шаги и в описание.

## hero

- Картинка: `docs/img/hero-jadlis-skill-builder.webp`
- Заголовок: «Процедура один раз ложится папкой»
- Слева: повторяющаяся задача обычными словами; подпись «Повторяющаяся задача»
- Справа: папка со скиллом, три части — сверху «Шаги», сбоку «Справочники», снизу «Скрипт»
- Рядом: сетка тест-промптов с отметками «прошёл / не прошёл»; подпись «Тест-промпты»
- Петля от тест-промптов возвращается в «Шаги», на стрелке подпись «правки»
- Названия сервисов, файлов и моделей в картинку не идут: только категории
